This is an ESPHome component that allows to use the ESPHome's display rendering engine with GP12XX vacuum fluorescent displays (VFD) from Futaba.

It was planned to support all known variations such as GP1287AI, GP1247AI, GP1294AI, and others.

However, I could only test the component with the GP1294 display as that's all I have, but it should be pretty easy to implement other displays.

If you have one of the unsupported displays to test the component with, please create an issue and I will add it to the component.
